# Revalor — Give Waste Its Next Value ♻️

Revalor is an AI-powered e-waste recovery platform that helps users:

**Scan → Understand → Value → Find → Collect → Track → Impact**

## 🚀 Key Features

- 🤖 AI-powered e-waste scanner
- ♻️ Find nearby recyclers
- 📦 E-waste pickup request & tracking
- 🎁 Rewards, points & badges
- 📊 Environmental impact dashboard
- 🏢 Organization dashboard
- 🛡️ Admin dashboard
- 🧪 Demo Mode with no API keys or database required

## 🛠️ Tech Stack

- Next.js
- TypeScript
- Prisma
- PostgreSQL
- AI Integration
- Tailwind CSS
